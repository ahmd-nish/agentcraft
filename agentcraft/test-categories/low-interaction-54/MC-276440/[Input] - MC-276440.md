## Description

The Bug:
Items within bundle tooltips can be unselected by scrolling despite only one item being present.
Within the game, when there is only one element on the screen, if you were to select it using keyboard navigation, you would notice that it cannot be unselected because there are no other elements on screen. However, within bundle tooltips, you can unselect an item despite it being the only item within the bundle which is inconsistent.
Steps to Reproduce:
- Obtain a bundle and fill it with one block of stone.

- Hold your mouse cursor over the bundle and begin scrolling constantly and observe if the stone is constantly selected and unselected.

Observed Behavior:
Items within bundle tooltips can be unselected by scrolling despite only one item being present.
Expected Behavior:
Items within bundle tooltips would not be able to be unselected by scrolling despite only one item being present.
