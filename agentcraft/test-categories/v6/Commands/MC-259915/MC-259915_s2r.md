BUG_ID: MC-259915

AFFECTED_VERSION: Minecraft Java Edition 1.20.1

BUG_BEHAVIOR:  
An item display moved through repeated small teleports visually snaps to each new position instead of interpolating smoothly between positions.

PRECONDITIONS:

- Launch unmodified Minecraft Java Edition 1.20.1.
- Create or open a singleplayer world with commands enabled.
- Use first-person view.
- Ensure entity rendering is enabled and the test area is visible.
- PRACTICAL_ASSUMPTION: Run the client above 20 FPS, preferably at least 60 FPS. This makes the difference between tick-by-tick snapping and smooth client interpolation visible.
- Do not add a `teleport_duration` tag. That control was introduced in snapshot 23w31a and is not part of the affected 1.20.1 behavior. ([minecraft.net](https://www.minecraft.net/nb-no/article/minecraft-snapshot-23w31a?utm_source=openai))
- PRACTICAL_ASSUMPTION: The report supplies no exact command or coordinates. This reproduction uses a diamond-block item display and a stationary pig as a living-entity interpolation comparator. Both receive the same repeated teleport operation.

SETUP:

1. Enter Creative mode:

```mcfunction
/gamemode creative
```

2. Remove entities left by an earlier attempt:

```mcfunction
/kill @e[tag=MC259915_MOVE]
```

A “No entity was found” response is acceptable.

3. Remove any earlier test command block:

```mcfunction
/setblock 0 99 0 minecraft:stone
```

4. Create a flat observation platform:

```mcfunction
/fill -16 99 -2 16 99 16 minecraft:stone
```

5. Set clear daytime conditions:

```mcfunction
/time set day
```

```mcfunction
/weather clear
```

6. Position the player at `(0, 100, 0)`, looking horizontally toward positive Z:

```mcfunction
/teleport @s 0 100 0 0 0
```

VERIFY:

- The player is standing on the platform.
- The camera is looking horizontally across the platform.
- The center of the view points toward approximately `(0, 102, 8)`.

7. Summon a pig at the left side of the view. It will serve only as a smooth-position comparator:

```mcfunction
/summon minecraft:pig -5 100 8 {Tags:["MC259915_MOVE","MC259915_CONTROL"],NoAI:1b,Silent:1b,Invulnerable:1b}
```

8. Summon the affected item display directly above the pig:

```mcfunction
/summon minecraft:item_display -5 102 8 {Tags:["MC259915_MOVE","MC259915_DISPLAY"],item:{id:"minecraft:diamond_block",Count:1b},item_display:"fixed",Glowing:1b}
```

VERIFY:

- A stationary pig is visible near the left side of the view.
- A glowing diamond-block item display is visible above it.
- Neither entity is moving.
- If they are not visible, repeat step 6 and do not change the camera direction afterward.

REPRODUCTION_STEPS:

1. While continuing to face the two entities, create an always-active repeating command block directly under the player:

```mcfunction
/setblock 0 99 0 minecraft:repeating_command_block[facing=down]{Command:"execute as @e[tag=MC259915_MOVE] at @s run teleport @s ~0.25 ~ ~",auto:1b,TrackOutput:0b}
```

This command teleports both test entities exactly `0.25` blocks along positive X once per game tick.

2. Immediately close the chat overlay and watch both entities move laterally across the screen for approximately 2 to 4 seconds.

VERIFY:

- Both entities move in the same direction and at the same average speed.
- The pig’s client-rendered position transitions comparatively smoothly.
- The item display remains at one rendered position for several frames and then visibly jumps to its next tick position.
- Focus on positional movement, not the pig’s limb animation or either entity’s rotation.

3. Stop the test after the entities cross the view:

```mcfunction
/setblock 0 99 0 minecraft:stone
```

EXPECTED_BEHAVIOR:

The item display should visually interpolate between successive teleport positions, producing continuous movement similar to the pig.

OBSERVED_BUG_BEHAVIOR:

The pig moves smoothly between its updated positions, but the item display advances in discrete, visible steps. The item display snaps approximately `0.25` blocks on each update with no client-rendered positions between those updates.

SUCCESS_CONDITION:

Reproduction succeeds if, while both entities receive the same `~0.25 ~ ~` teleport every tick:

- the pig displays smooth lateral positional motion, and
- the item display visibly freezes between updates and then snaps to each new position.
