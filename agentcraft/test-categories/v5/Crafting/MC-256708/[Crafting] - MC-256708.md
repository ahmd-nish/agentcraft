## Description

You can use bamboo mosaic slabs in recipes, but not bamboo mosaic.
This is a bug that can go two ways.
Steps to Reproduce:
1. place a crafting table
2. grab bamboo mosaic and bamboo mosaic slabs into inventory
3. try to craft a barrel or a chiseled bookshelf
4. grab e.g. oak planks and try again with the oak planks and bamboo mosaic slabs
Observed Results:
Bamboo mosaic slabs can be used for crafting and bamboo mosaic cannot
Expected Results:
1. it is not possible to make anything with bamboo mosaic slabs
or 2. it is also possible to make something with bamboo mosaic
