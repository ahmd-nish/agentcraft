## Description

The Bug:
The fog from lava is much denser in java edition when having the fire resistance effect active compared to bedrock edition.
Steps to Reproduce:
- Launch the java edition version of the game and join a world.

- Drink a fire resistance potion and enter a large area of lava.

- Take note of how dense the lava fog is.

- Launch the bedrock edition version of the game and join a world.

- Drink a fire resistance potion and enter a large area of lava.

- Take note of how dense the lava fog is compared to java edition.

Observed Behavior:
The fog from lava is much denser in java edition when having the fire resistance effect active compared to bedrock edition.
Expected Behavior:
The fog from lava in java and bedrock edition when having the fire resistance effect active would have the same density.
