## Description

Summary
Fletcher villager's master trade includes tipped arrow for each potion (except Luck). This allows obtaining a tipped arrow of Infestation, Oozing, Weaving, or Wind Charged, without enabling the 1.21 experiments. The attached world includes a fletcher who sells weaving arrows.
Steps to Reproduce
- Create a world without 1.21 experiments.

- Spawn a fletcher.

- Trade to the master level.

- Check the traded tipped arrow. Note that this trade is not guaranteed.

Expected Result
Fletcher does not sell new tipped arrows.
Actual Result
Fletcher sells new tipped arrows.
