## Description

Moderator note
For anyone who opened their world in 20w17a and is still experiencing this issue in versions after 20w17a:
Try optimizing the world:
Important: Depending on the world size this may take a while.
- Client:
- Select the world on the world selection screen

- Press the "Edit" button

- Select "Optimize World"

- Check "Erase cached data"

- Press "Create backup and load"

- Revisit the area located on the map to update it

- Server:
- Create a backup by copying the world folder

- Start with --forceUpgrade --eraseCache

If you are still experiencing this issue after trying the steps above, please comment and attach the world (in the version before you opened it in the latest version of the game) as zip file.
