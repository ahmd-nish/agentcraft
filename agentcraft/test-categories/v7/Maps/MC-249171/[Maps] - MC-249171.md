## Description

The bug
The map color for mangrove logs is incorrect. Unlike the stripped mangrove log, which appears red on a map, the mangrove log matches the color of acacia logs on a map, which is orange.
How to reproduce
- Obtain and fill a map

- Place upward-facing acacia logs
 The logs appear orange on the map

- Place upward-facing stripped mangrove logs
 The logs appear red on the map

- Place upward-facing mangrove logs
 The logs appear orange on the map

Expected behavior
The mangrove log color would be red, like the map color of stripped mangrove logs.
Actual behavior
The mangrove log color is orange, like the map color of acacia logs.
