## Description

The bug
All other bucketable mobs (cod, salmon, tropical fish, pufferfish, axolotl, tadpole) do not despawn when placed from a bucket. However, sulfur cubes do despawn when placed from a bucket, unless otherwise persistent.
How to reproduce
- Get a sulfur cube bucket, from the creative inventory or from picking one up

- Place it

- Fly away

- Fly back

Expected result
It should still be there
Observed result
It’s gone
