## Description

Since Bedrock 1.16.100 update, the renamed minecarts and boats show their name tag in the world above it. This doesn't happen on Java, which creates parity issues.
Step to Reproduce
1. Get an anvil.
2. Rename a minecart/boat
3. Place a boat down, place the minecart on rails.
Observed Result
Their name tag doesn't show up.
Expected Result
The name tag should show up.
