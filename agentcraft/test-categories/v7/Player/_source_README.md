# Updated Player bug-report set

This package retains `MC-184530`, `MC-65931`, and replaces `MC-19690`, `MC-2791`, `MC-697`.

Replacement criteria:

- Minecraft: Java Edition (`MC`)
- resolution `Fixed`
- native Mojira category includes `Player`
- created on or after 2022-01-01
- does not carry the `Crash` category
- selected by newest creation date first

Each bug folder contains the readable report, unaltered Mojira API response, and all available attachments.
