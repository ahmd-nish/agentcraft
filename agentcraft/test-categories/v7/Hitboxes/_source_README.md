# Latest Hitboxes reports created after 2021

This package contains the five newest eligible Minecraft: Java Edition reports that:

- carry the native Mojira `Hitboxes` category
- have resolution `Fixed`,
- were created on or after 2022-01-01, and
- do not carry the excluded `Crash` category.

Each bug folder contains the readable report, unaltered Mojira API response, and downloaded attachments.
