## Description

The bug
 was fixed in 23w18a, and  was fixed in 1.20 pre-release 1. However, iron golems produce step particles for blocks they walk on, and these can be for blocks they're not colliding with, and are generated in midair.
How to reproduce
- Build a setup like this:

- Create an iron golem within

- Observe as it walks

Expected results
The particles generated by the iron golem as it walks would only be those of the solid full blocks it collides with, and would always be generated above those solid blocks.
Actual results
It creates particles of the blocks it's not colliding with as well, and oftentimes these are created in midair.
